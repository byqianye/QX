# QX影视文档入口

新任务按这个顺序阅读：

1. [项目接手入口](PROJECT-HANDOFF.md)
2. [当前状态台账](PROJECT-STATUS.md)
3. [项目文件结构](PROJECT-STRUCTURE.md)
4. [构建与打包](BUILD.md)
5. [维护规则](MAINTENANCE.md)

其他文档按主题分组：

- `user/`：用户操作说明
- `source-contract-*.md`、`source-adapter-*.md`：源适配合同和接入流程
- `reports/goals/`：Goal 结果和验收报告
- `reports/audits/`：专项审计
- `reports/testing/`：测试与打包验收
- `design/`：UI 设计产物
- `spike-*.md`：历史可行性探针

`PROJECT-STATUS.md` 是持续状态的唯一入口；其他报告完成后从那里回链。
