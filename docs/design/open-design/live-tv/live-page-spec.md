# Live source page spec

## 顺序

1. 页面标题与当前 VOD 连接摘要
2. 「导入与预览」表单
3. 预览统计、频道名和诊断
4. 「已保存」来源列表

## 状态

| 状态 | 页面表现 | 用户动作 |
| --- | --- | --- |
| 空 | 说明还没有已确认来源 | 添加 URL 或文件 |
| 预览 | 显示频道/分组/线路/无效数和问题行 | 确认导入或清除 |
| 已保存 | 显示启停、数量、最近成功时间和最近错误 | 刷新、停用/启用、移除 |
| 刷新失败 | 保留旧数量并显示脱敏错误 | 修正来源或重试 |

EPG、频道播放和自动切源不在此页面实现。
