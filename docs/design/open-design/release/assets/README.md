# G73 release assets

The source mark is kept here for OpenDesign traceability. The generated Windows ICO is produced deterministically from the same local mark by `npm run brand:assets` and is emitted at `build/assets/qx-yingshi.ico`.

- Source mark: `qx-yingshi-mark.svg`
- ICO sizes: 256, 128, 64, 48, 32 and 16 px
- No remote fonts, images, CDN or runtime asset fetches are used.
