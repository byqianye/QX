05 · Installer / bundle review

Installer

Per-user NSIS；可选安装目录；默认保留用户数据；桌面和开始菜单快捷方式使用同一 ICO。安装、升级、卸载和离线启动均需要独立验证。

Renderer lazy loading

Local、Live、Downloads 和 EPG 设置路由使用 async component。记录初始 chunk、路由 chunk 和首启状态；不通过调大 warning limit 掩盖 bundle 问题。
