# 安装、升级与卸载

QX影视 Windows x64 安装包采用 per-user 安装，不要求系统预装 Java、Python、mpv 或 aria2，也不会默认注册视频文件关联。

## 安装与升级

运行 `QX影视-0.1.0-setup.exe`，按向导选择安装目录。升级时直接运行新版本安装包，不要先删除 `%APPDATA%\QX影视`；应用会保留用户数据并执行已有数据库迁移。

## 卸载

卸载默认保留设置、历史、收藏、追更、备份和缓存。只有在卸载器中主动选择删除用户数据时，才会清理用户数据目录。

## Portable

Portable 版需要把 `QX影视.exe` 与 `data` 目录放在同一可写目录。Portable 与安装版使用不同数据目录，建议分别备份，不要混用。
