# 已知限制

- 不支持 DRM 播放或 DRM 绕过。
- 不承诺 Android DEX 通用兼容，也不承诺所有 TVBox/FongMi Spider 兼容。
- 不保证全部 IPTV、视频网站或第三方服务接口可用；兼容性取决于来源和引擎。
- 不内置第三方影视源、付费解析接口、测试账号或托管解析服务。
- 第三方实时弹幕能力有限，不能作为所有内容的必备功能。
- Web 控制仅面向用户信任的 LAN，不提供公网云端远控。
- 当前 G73 OpenDesign packaged 视觉验收和 G76 clean Windows 安装/升级/卸载/离线/非 ASCII 路径矩阵尚未完成；在这些 Gate 通过前，不应将当前构建称为稳定生产版。
